Before you edit

  • Quit Valheim completely first, or the game will overwrite your changes on its next save.
  • Keep a copy of the original file. Folder mode makes a backup automatically.
  • Only the inventory and skills sections are rewritten. Every other byte is copied from the original.
  • With Steam Cloud, pick “keep local” if Steam reports a sync conflict afterwards.

About cheat flags

  • Valheim 1.0 stores a per-character used cheats flag and a per-item cheated mark. Either one blocks achievements.
  • This editor never sets either one. Editing quality, items or skills leaves them exactly as they were.
  • If a character already carries a flag, the Integrity tab can clear it on request.
  • Items you add are stamped as crafted by your character, the same way a normal crafting-table item is.
  • Whether a server accepts edited characters is up to that server.

What this editor guarantees

  • The usedCheats flag is copied from the original unchanged unless you press Clear flag. It can never be set by this editor.
  • Each item's cheated bit is copied unchanged unless you clear it; new items are written with it clear, like a crafted item.
  • Only the inventory and skills sections are re-encoded. Apart from that one optional flag byte, the bytes before, between and after them are identical to the original.
  • The SHA-512 checksum is recomputed over the new payload.
  • The written file is re-parsed before it is handed back, and the result must match what you edited.
